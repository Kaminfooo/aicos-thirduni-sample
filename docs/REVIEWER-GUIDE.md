# AICOS usage guide

## Start here — no camera or login needed

1. Open the operations link. On Render Free, allow the service to wake; if necessary use Check connection after the page loads.
2. Choose **Start guided walkthrough**. It selects the person-down reference detector; the other categories remain available under Detectors & zones.
3. Optional: open Camera & event map, enter an explicitly illustrative test site and coordinates, and Apply camera location before starting. Do not use a private home address for a public demonstration. Pins represent the chosen camera position, not the licensed recording's actual origin.
4. In Detection lab, choose Controlled fall simulation and Analyse supplied recording. The browser sends sampled frames for fresh inference. Observe the increasing frame count and detector results; a working preview alone is not detection.
5. When an alert is raised, inspect its triggering image and surrounding sampled clip. Stored signed evidence verification checks integrity, not interpretation.
6. Write a short observation with uncertainty, such as: “A person is visibly lying down in this controlled simulation; medical cause unknown.” Accept the review draft, then separately Approve incident. Inspect the audit entries.
7. Open the map and select the retained event to return to its evidence. Export run downloads measurements and observed decisions; it is not a signed evidence export or an accuracy certificate.
8. Start a new run with Walking reference. That short reference has previously stayed quiet. A quiet result does not establish safety in all scenes.

## Optional live camera and surveillance wall

Add a named camera tile with its site and coordinates. Browser camera uses the visitor's own device with explicit permission and no audio. Select Connect, then select that feed and choose Analyse selected feed. The wall shows the selected detector list, actual frame/alert counts and an ANALYSING badge. Other tiles remain previews.

The current run stops after 90 seconds, an enabled pause-on-alert condition, a stopped input or an error. Only one feed runs detection at a time. Raw RTSP/ONVIF is not supported directly in the browser; use an already compatible HTTP streaming gateway. Coordinate fields accept decimal degrees or DMS. An existing tile keeps its own saved metadata; changing the separate map form does not rewrite that tile or past events.

Do not stage a fall, fire, smoke, violence or an emergency. Ordinary activity and supplied licensed recordings are sufficient for review. Real-time person-down misses have been observed, so a live posture attempt is not the recommended acceptance path.

## How to interpret the controls

- The green Test region is a configured image rectangle for zone/site/traffic rules. Person-down and fire/smoke are not restricted to this rectangle.
- “Connected” is video preview status. “Analysing” with an increasing frame count is active detection. A frozen feed is stopped/marked stale rather than treated as current video.
- The 12 categories are integrated, but research-preview labels identify incomplete recognition validation. Reliable general violence, panic, theft and unattended-object recognition has not been established.
- A model score is not measured accuracy. Camera coordinates are not exact person coordinates. Demonstration procedures are not approved site-response SOPs.
- Reviews and approvals are isolated demonstration actions. They do not contact emergency services or grant production administrator access.

## Recovery and privacy

If a model, stream or network request fails, inspect the visible message and start a new run; writes are not silently retried. Disconnect feeds when finished. Reloading clears page-local camera configuration. Restarting the free hosted service clears its demo sessions/evidence and signing identity. No production incident history is connected.

Public map tiles require internet and disclose the viewed map area/IP to OpenStreetMap. No footage or event notes are sent to the tile provider. Use the supplied recordings if you do not want to grant camera or location permission.
