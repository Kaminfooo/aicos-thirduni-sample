# Record the current AICOS product — target 3 minutes

The supplied ThirdUni rules require a 2–4 minute product video on YouTube or Google Drive, accessible without requesting permission. Unlisted is allowed; private is not. Screen recording with your voice is enough. Show the actual working product, disclose earlier work and AI assistance, and do not claim that research detections are validated.

## Before recording

- Use the final tested product URL, or clearly say that this is the local product if cloud deployment is not working. Do not present the old replay sample as the new full platform.
- Use a fresh page/session. Close tabs, notifications and password managers; remove home coordinates, private stream URLs and personal camera configuration from view.
- Select person-down reference only for the main workflow. Use the supplied controlled recording rather than performing a fall.
- If showing map integration, apply a clearly labelled illustrative public test position before analysis. Say it is a configured demo camera position, not the source recording's location.
- Rehearse the complete alert → evidence → review → separate approval → audit once. If a run misses, do not describe that run as successful; explain the limitation and use the demonstrated sampled-reference path.
- Use the instructions below as a shot list, not as claims about customers, pilots, revenue or reliability.

## Shot list and suggested voiceover

**0:00–0:25 — product visible, overview.** “This is AICOS. It helps camera operators inspect possible safety incidents and make traceable decisions using the associated video evidence. I am focusing on one complete workflow: person-down alert, evidence review and human approval.” Briefly show the operations dashboard; do not spend this section on slides.

**0:25–0:45 — configuration and optional map setup.** Show Person-down reference and the supplied controlled simulation. If demonstrating mapping, show the illustrative camera position/label already applied. “This is licensed laboratory footage, not a real emergency. The map position is illustrative.”

**0:45–1:20 — fresh analysis.** Select Analyse supplied recording and show the increasing frame count and actual detector result. “These sampled frames are analysed now using the reference model. This does not establish a medical cause or guarantee detection in other environments.” Allow the actual run to complete or pause on its alert; do not fake an alert or substitute a recorded-output page without disclosure.

**1:20–2:00 — evidence, human review and decision.** Show the triggering image and sampled clip, signed evidence verification, write an observation, Accept review draft, then separately Approve incident. Show the new audit entries. “Integrity verification checks the stored evidence. The operator still decides what it means. Accepting a draft and approving the incident are separate recorded actions. Nothing is dispatched.”

**2:00–2:25 — map and surveillance.** Select the mapped event and return to evidence. Show the camera surveillance window. You may connect a normal webcam preview if you choose to share it, or show clearly labelled reference playback. “The wall supports named preview feeds and camera locations. Only one selected feed runs detection at a time; nine preview tiles is not a processing-capacity claim.” Do not call reference playback a live camera.

**2:25–2:45 — what you built and honest limits.** “AICOS started before ThirdUni. During October I improved evaluation, pose confirmation, operational health, evidence-linked review, and the operations dashboard, map and camera wall. Real-time person-down misses remain, and violence and several interaction detections are research previews. The supplied reference workflow is the demonstrated core.”

**2:45–3:10 — contributors and next step.** “I am Kamal Belkheiri, the solo project owner. Claude assisted the original starter, and ChatGPT/Codex assisted implementation, debugging, tests and documentation. Pretrained models and licensed footage are credited in the repository. Next I will validate missed detections and false alerts on independently labelled, permitted footage before a measured pilot.” Show the repository README briefly if it is already public.

## Final video/link QA

Keep the product readable and the total length between 2 and 4 minutes. Upload to YouTube as Unlisted or make the Google Drive video accessible to anyone with the link. Open the actual video URL in a private window while logged out and play the start, middle and end. Verify the repository is public with a README and the demo link still works. ThirdUni closes at 23:59 on 31 October; check links on 30 October and save well before the final evening. Do not use a private video or private repository as a workaround.
